# taller_excel_pdf_Emanuel

Script en Python que automatiza el procesamiento del inventario de ventas de la empresa ficticia TecnoVentas. El programa lee la base de datos ventas_tecnologia_v2.xlsx con openpyxl, muestra la información formateada en consola con tabulate y genera automáticamente un informe ejecutivo en PDF con ReportLab.

Incluye un menú interactivo con las siguientes funciones:

Ver el catálogo completo, con métricas de resumen (total de unidades vendidas y precio promedio).
Filtrar los productos con precio superior a $100.
Buscar un producto por ID.
Exportar el informe reporte_ejecutivo_ventas.pdf, con fila final de resumen.
Salir del programa.
